Day 79 -> Widget and Grid


grid() in Tkinter:
grid() is a geometry manager used to place widgets in a table-like structure (rows & columns).

Why Use grid():
Allows clean, organized layout.
Easier to align widgets in rows and columns.
More control than pack() when building forms or dashboards.

Widget in Tkinter:
A widget is any GUI element provided by Tkinter, such as:
Label – to display text.
Button – to perform actions.
Entry – for input fields.
Frame – to organize other widgets.
Text, Canvas, Checkbutton, etc.
Widgets are building blocks of any Tkinter window.
