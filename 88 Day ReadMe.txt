Day 88 -> ListBox 


A Listbox in Tkinter is a GUI widget used to display a vertical list of items from which the user can select one or more entries. 
Each item in the list is displayed on a separate line, and the widget can be configured for single selection (only one item can be chosen) or multiple selection (several items can be chosen at once). 
It provides built-in methods like .insert() to add items, .delete() to remove them, and .get() to retrieve the selected or specific items. 
This makes it useful for creating menus, selection lists, and item displays in applications.
