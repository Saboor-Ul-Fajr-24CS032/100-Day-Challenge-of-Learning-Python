Slider (Scale) in Tkinter:
A Slider (or Scale) is a widget used to select a numeric value by dragging a slider.
You can set the range, direction (horizontal/vertical), initial value, and tick intervals.

Options:

from_: starting value
to: ending value
orient: "horizontal" or "vertical"
tickinterval: spacing between ticks
set(value): sets the default position
get(): returns the current slider value
