Day 80 -> CheckButtons and Entry Widgets


Checkbutton Widget:
A Checkbutton allows the user to select one or more options from a set.
Each checkbutton can be checked (on) or unchecked (off) independently.
It’s used when you want to provide multiple selectable choices.

Entry Widget:
An Entry widget is used to accept single-line text input from the user.
It is commonly used for usernames, passwords, or numbers.
