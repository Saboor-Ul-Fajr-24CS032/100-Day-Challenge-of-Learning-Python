 Day 89 -> ScrollBar

A Scrollbar in Tkinter is a control element that lets the user move horizontally or vertically to view hidden parts of the content inside a widget.

Key points:

Orientation: Can be "vertical" or "horizontal".
Connection: Works by linking to another widget using the command option (e.g., yscrollcommand for vertical, xscrollcommand for horizontal).
Usage: Common with Text, Listbox, or Canvas when content exceeds the display area.
Function: It sends movement commands (like scroll up or scroll down) to the linked widget and updates itself when the widget’s view changes.
